# Ring Rítmico

Boxeo rítmico en VR (WebXR) para Meta Quest.

- **Jugar en el navegador de tus Quest:** https://togashi16.github.io/ring-ritmico/ y pulsa "Entrar en VR".
- **APK para instalar:** https://github.com/togashi16/ring-ritmico/releases/latest/download/ring-ritmico.apk
  (se instala con SideQuest o Meta Quest Developer Hub; aparece en "Orígenes desconocidos").

Cada cambio en `main` vuelve a construir el APK con GitHub Actions (`.github/workflows/apk.yml`).
La clave de `android/android.keystore` es solo para instalación propia (sideload), no para publicar en la tienda.
